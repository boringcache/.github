# BoringCache Support

Start with the [BoringCache documentation](https://boringcache.com/docs),
especially [Troubleshooting](https://boringcache.com/docs/troubleshooting).

For account, workspace, billing, or product help, email
[support@boringcache.com](mailto:support@boringcache.com). Include the CLI
version, failing command, tool and platform, CI job URL or approximate run time,
and reviewed `boringcache doctor` output when relevant. Never send tokens,
credentials, or customer data.

Use a public repository issue for a reproducible problem with that repository's
public artifact, documentation, or workflow. Search existing issues first and
include the smallest useful reproduction.

Potential vulnerabilities must be reported privately through
[security@boringcache.com](mailto:security@boringcache.com) or the repository's
private vulnerability reporting form, not through a public issue.
